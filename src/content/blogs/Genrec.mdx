The genrec architecture itself is pretty intuitive and ingeneous. It commpiles a row into a singular prompt and passes it through a autoregressive model 
to get the score. The final lm_head is used ONLY in the training phase to prevent too much drift and catastrophic destruction of the pretrained knowledge
of the model. The real novelty is a separate last layer head which has all items in the catalogue - the output is the probability of the user liking 
the given item from that catalogue. there is no expensive autoregressive step. just prefill -> output.
